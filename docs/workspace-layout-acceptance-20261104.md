- 聊天与左侧历史记录保持原位，个人空间使用已有的右侧可调宽面板；手机宽度使用覆盖式工作区。
- 顶部固定显示受管逻辑存储总量、额度、进度和采样时间；不完整用量明确标注，刷新失败保留旧值并继续轮询。

- 文件和应用采用共享组件新增的分段导航样式，默认标签组件样式不变。
- 应用按状态、访问地址、CPU/内存、日志和更新发布组织；启停和删除放进菜单，删除须确认。
- 移除用户工作区的数据库入口及应用数据库详情，保留后端数据和用量计量。套餐明细以“应用数据”呈现相应用量。
