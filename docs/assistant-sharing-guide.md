# 可用助手与分享管理

## 找到并使用助手

左侧打开 **可用助手**，选择“全部”“我发布的”或“分享给我的”。列表只收录启用且已经正式发布的业务助手；草稿和私人试用留在项目中。OpenHands 编程助手是系统开发入口，不能删除，编程选项继续在其对话中配置。

点击 **打开使用** 会打开新标签页，核验权限后开始对话，当前聊天和未发送内容保留。正式会话固定其开始时的版本；发布新版后，新会话使用新版，旧会话不会被改绑。

## 发布与分享

1. 在项目的 **助手 → 试用与验收** 核对真实回答和资料来源，记录验收通过。
2. 打开 **发布**，确认版本、应用总预算和由创建者承担模型费用，再发布。
3. 在 **可用助手 → 我发布的 → 发布与分享**，或项目发布页面，填写对方的已验证邮箱或其提供的账号 ID，设置成员额度和可选到期时间，再发送邀请。
4. 对方登录后，在 **可用助手 → 待接受邀请** 选择接受或拒绝。接受前不能调用。当前通知就在这个入口，不发送邮件或短信。

账号 ID 可在助手访问页的“我的账号 ID”查看。不存在、不可用或未验证的邮箱无法用于邀请；不要用修改账号验证状态来绕过检查。重复邀请不会重复授权或清零用量。

## 额度与撤回

- 模型费用由创建者支付。成员额度是该应用总预算内的累计使用上限，**不是给成员充值**，也不是每次发布重新赠送的额度。
- 成员列表分别显示已结算、在途/待核验费用、累计上限和到期时间。预算同时受应用总上限和创建者模型账户可用余额约束。
- **调整额度与有效期**：可以增加或减少上限，设为 0 可阻止新模型调用；留空额度表示沿用应用总上限。减少额度不会撤销已发生费用，低于已占用时不能继续调用。
- **撤回分享**：确认后禁止后续使用，已发生的调用仍按真实结果结算，不删除旧聊天。成员从可用列表消失；其他设备列表默认在下一次刷新（约 10 秒）更新，但直接打开旧链接或继续旧会话会立即核验权限，不能绕过撤回。
- **重新邀请**：必须由成员再次接受，保留累计用量。重新邀请默认清除旧到期时间，需要时重新设置；不会清除撤回前的费用。
- **到期**：拒绝后续调用；创建者可调整有效期。已撤回或已拒绝的授权不会仅因调额度而恢复，仍需重新邀请。

受邀者只有使用权，没有编辑、删除、再次分享、查看私有配置或管理创建者项目的权限。同一账号仍可以管理自己创建的项目。

## 状态与异常

分享设置已变化时，刷新后再操作，避免覆盖另一处更新。请求超时先刷新查看实际状态，不重复发起模型调用；未知费用会保留占用，不能当作免费失败。更改知识资料、草稿或发布版本不会重置成员费用。

当前不开放匿名使用、公共助手审核目录或团队付费主体转移。创建者自身草稿与 LibreChat 原生历史助手不因该目录上线被删除或自动发布。
