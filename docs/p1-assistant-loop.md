# 智能体 LLM 与工具反馈画布

2026-11-08。用户授权的增量设计与实施清单。沿用原生项目、版本化草稿、试用和发布契约，不新增工作流引擎。

## 交互与数据契约

- 右侧上区固定高度，默认画布，下区独立对话。画布无悬浮卡片外框，沿用主题色。主对话创建和修改助手，下区使用固定试用版本，消息及未发送内容分别保存。
- 主路径为输入 → LLM → 回答。有已绑定的知识检索时，增加 LLM → 知识检索工具 → 执行结果 → LLM 回路。工具分支按需执行，不能表示为所有问题必经。
- 参数来自服务端已保存草稿。点击 LLM 编辑模型、指令和受支持参数，点击知识检索修改知识关联。拖动只保存布局，不能改变权限、执行顺序或线上版本。旧关系图坐标原样保留，新回路布局按账号与项目独立保存，不改变项目数据。
- 主对话“修改草稿”重新读取最新配置，模型建议携带草稿摘要。上下文包含知识检索的 available / unbound / unavailable 状态，不要求模型从版本编号猜测是否已就绪。保存时拒绝过期建议，手动修改不被静默覆盖。图显示草稿；下方仍在旧试用版本时显示简短版本差异标记，不将旧版执行状态附到新版图。
- 运行状态只从独立试用会话收到的生成与工具调用事件推导。仅显示真实调用完成、失败、中断、等待或生成，不推测模型内部思考，不用定时动画伪造循环。收到检索调用完成后显示反馈回路，模型继续输出时回到 LLM。
- 同一轮多次调用分别计数，历史消息、上一轮结果、其他窗口消息不得污染本轮。停止/错误不能标记为成功。若没有完成证据，状态为中断或未知。
- 只读知识检索沿用现有服务端授权。没有单次审批事件时不虚构“授权完成”节点。当前固定快照实际只支持 file_search；其他 Tool/MCP/原生 Skill 的绑定执行仍按 D 阶段单独交付。
- 发布仍需实际试用验收，使用不可变快照。草稿变更不改变旧会话或线上发布。凭据不写入图或跨窗口消息。

### 干预与边界

- 第一条草稿生成超过 120 秒验收等待窗口，原请求仍在运行。重新打开同一会话继续，没有重复提交生成。一次历史合成知识库读取返回 404，改为通过真实 UI 新建资料；一次断言误把最新知识回答当成早先暗号回答，改为定位保留的历史消息，再从已保存的新版草稿继续。
- 窄屏截图发现原画布缩放没有响应尺寸变化，反馈线标签也可能与回答节点相交。最终布局将反馈回路移到下方。第一次仅依赖尺寸变化调用 fitView 的修复未通过窄屏节点边界检查；最终保留受控节点的测量尺寸，按容器大小直接适配视口，真实浏览器复验通过。
- 使用指定账号现有模型额度，未修改计费规则或权限，未清理原项目与会话。本轮未汇总费用，不代表计费专项验收。测试文件均为合成内容。
- 本轮真实调用覆盖知识检索，未接通其他 MCP 工具或原生 Skill 的固定快照执行。未做任意连线、历史回放或自定义工作流引擎。
- 主对话从“对话修改草稿”入口读取最新已保存配置；不宣称每条普通聊天都自动插入参数，也不把未保存的表单输入交给模型。节点坐标只在当前浏览器按账号、项目保存，不属于发布快照。
- 模型生成延迟仍需优化。没有据此宣称商业稳定性、多人无协助使用、性能门槛或独立安全评审通过。下一最高优先级为生成草稿的延迟与失败反馈，按相同项目路径重复测量。
