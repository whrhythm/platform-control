# 文件打开闪动修复与验收

日期：2026-11-05。问题发生在点击文件打开面板时，而非预览与编辑模式切换。

## 原因与修复

原先文件请求和编辑器懒加载期间只呈现一行加载文字；编辑器就绪后，内容区域突然变高，居中弹窗重新定位。文件内容状态初始化前也可能短暂呈现空编辑器。

- 从首次呈现开始预留完整内容区域，文件请求、编辑器代码加载和编辑器初始化使用同一加载提示。
- 文件初始内容准备好后才挂载编辑器，保留已打开版本的 ETag 和未保存修改保护。
- 编辑器创建前设置当前主题，避免初始化时使用不符主题的默认样式。
- 图片在预览地址生成前保持加载状态，不再短暂进入文本编辑器分支。
- 删除确认框保持原来的紧凑布局。

## 实际浏览器验收

使用指定验收账号，仅创建、编辑、删除临时文件 `qa-file-opening-20261105.py`，未修改已有文件。浏览器仅信任经集群 CA 验证后的站点证书公钥，没有安装系统根证书。

将文件请求延迟 1.5 秒，在打开动画结束后持续采样弹窗位置与尺寸，覆盖文件加载到编辑器显示内容的阶段。
