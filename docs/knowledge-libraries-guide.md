# 知识库使用手册

更新：2026-11-08。适用于已部署的 B 批次；入口位于 LibreChat 左侧「资料空间 → 知识库」。

## 准备和管理资料

1. 点击「新建知识库」，填写名称。空知识库可以先建立，稍后上传资料。
2. 打开库，点击「上传资料」。当前支持 UTF-8 的 Markdown（`.md`）与纯文本（`.txt`）；实际文件数量、大小限制显示在窗口中。
3. 文件右侧依次为预览、编辑、重命名、删除。预览与编辑使用同一窗口，有行号和高亮；铅笔进入编辑，保存后自动重建索引。
4. 状态为「索引中 / 就绪 / 索引失败」。失败可重试；存在上一份就绪资料时，项目草稿继续使用上一份，界面会明确提示。

一个账号可以创建多个独立知识库，例如「团队制度」和「产品说明」。它们不属于某一个项目的文件夹，同一库可被多个自有助手项目引用。当前每个助手选择一个库，尚不支持多个库合并检索。

## 让助手使用知识库

在左侧原生项目列表展开项目，进入「助手 → 资料」，选择知识库并保存。资料就绪后，在「试用与验收」点击「生成试用版本」，再打开预览提问并核对来源。

选库只影响项目草稿。已有试用、已发布版本与旧会话保留原知识修订；资料更新后需要创建新试用，确认效果再正式发布。不能把“文件保存成功”理解为“线上助手已更新”。

知识库、助手和普通文件的区别：

| 入口 | 用途 |
| --- | --- |
| 资料空间 → 工作文件 | 代码、开发依赖、生成文件及普通持久文件 |
| 资料空间 → 知识库 | 给助手检索的资料及其修订、索引 |
| 个人菜单 → 聊天附件 | LibreChat 原生聊天上传附件 |

上传到其中一个入口不会自动复制到另外两个入口。知识检索是助手可使用的能力，知识库本身不是一个完整助手。

## 容量、删除与故障

- 库顶部总占用包含保留的历史原文与索引，计入账号逻辑空间；文件旁的大小仅表示该文件的原文大小。它不是底层磁盘物理占用读数。
- 删除一个文件会生成新的资料修订，历史版本不会立即消失。在「历史修订与容量」可以清理未被引用的旧版本；当前编辑版、当前可用版和固定试用/发布引用版受保护。
- 「知识库设置与关联」显示关联项目和固定试用数量。仍有引用时拒绝删除整个库，避免让原助手失去资料；当前没有强制清空受保护版本的入口。
- 无引用的库可删除，后台清理原文和索引，完成后释放容量。清理遇到暂时故障会重试，不提前把占用算作零。
- 两个页面同时修改时，旧页面保存会提示冲突。请先复制保留自己的未保存文字，再重新打开最新文件合并；不会静默覆盖较新的资料。
- 正常关闭编辑窗口会提示未保存改动。当前未提供跨浏览器、刷新或崩溃后的编辑草稿恢复承诺，请及时保存。

当前默认上限：20 个库，每库 10 个文件、单文件 1 MiB、20 份未清理修订；由平台设置控制，以界面实际限制为准。PDF、Word、图片、音视频解析、公共知识库和多库联合召回尚未开放。
