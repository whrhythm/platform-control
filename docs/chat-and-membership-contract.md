# 聊天、模型与套餐改进协议

本阶段优先解决用户提出的九项体验问题，暂停跨存储扩容工作。

- 能力和模型是两个字段。普通聊天直接调用选定 LLM；编程调用个人 OpenHands 执行进程。原生智能体的模型列表只显示真实模型名称。旧路由名兼容读取，但不再作为可售模型展示。
- 管理员控制台提供普通聊天默认模型、编程默认模型、可用模型、人民币/美元结算汇率和套餐配置。保存有版本校验、权限校验和审计；用户不持有供应商管理密钥。
- 套餐重点是模型额度与参考 token 数、个人磁盘、发布应用数。不同模型输入/输出价格不同，token 估算标明依据，实际扣费以 LiteLLM 计费为准，不承诺金额对应固定跨模型 token 数。
- 注册赠送 1 美元一次。充值订单把人民币模型额度按服务端汇率快照折算为美元；10 元套餐增加等值美元预算。只增加 LiteLLM 的累计预算上限，保留历史 spend，不清零使用记录。用户级和 key 级上限同时核验。
- 支付继续使用明确标注的模拟流程。充值任务先落库，记录原上限、目标上限与归属，再执行绝对值写入并观察。重复确认、超时重试或进程重启复用同一任务；发现外部预算变化时转人工核验，不盲目覆盖。
- 同档套餐可以再次购买模型额度；已经分配的磁盘和应用权益不得被重复购买缩小。资源开通与额度到账分别显示，失败不删除用户数据。
- 中文优先，保留显式语言偏好。能力控件放进输入框底栏的加号旁；亮暗主题都明确标示选择。执行过程走可折叠进度，同类状态合并。
- 文件夹提供 ZIP 下载，包含子目录。压缩包、原始字节、文件数和执行时间均有上限；不跟随链接，失败不交付一个看似成功的残缺压缩包，临时包在请求结束清理。
- 新对话自动生成标题；历史默认标题只在属于本人且未手工命名时补充首条消息摘要，保留手工标题。

API 契约随 OpenAPI 一起更新。验证分别记录单元、真实 HTTP 模拟、实际 LiteLLM 预算变化和 LibreChat 中文亮暗主题界面，不能用其中一项替代其他项。
