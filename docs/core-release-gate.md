# 核心流程下一版交付与验收

> 历史探索草案，未完成验收及上线。HTML 与工单预览仅是局部测试范围，不能代表产品首发范围。产品方向和完整验收以[星桥产品纲领](product-charter.md)为准；相关本地改动待 P0 评估，不自动部署。

范围固定为“生成 → 可交互预览 → 修改 → 发布”。保持聊天、个人文件和已有应用；暂缓工作流、模板市场与其他功能扩展。

本批支持两条已存在的场景：内联资源的单页 HTML，以及售后工单样板。通用后端应用的离线 HTML 预览不等于后端已运行，不宣称支持任意工程即时启动。

## 契约

- 当前工程预览只读，由登录所有者获取有界源码快照。预览运行于无同源权限 iframe，禁止网络、顶层导航和外发；不注入身份凭据或业务库数据。
- 预览明确区分“当前草稿”和“已发布应用”，刷新预览重新获取代码并清除旧确认。工单预览使用示例数据。
- 从预览发起发布必须携带所见源码摘要，服务端提交和构建下载后均核对。改变代码时不得把新代码冒充已预览版本。已有发布和 Agent 接口保持兼容。
- 没有 Dockerfile 的单页 HTML 可用平台固定的静态发布方案，仅复制 index.html 到镜像，不公开其他工程文件。已有 Dockerfile 不覆盖。不开启任意后端的自动推断构建。
- 发布失败保留文件和业务数据；结果不明仍按现有核验机制处理，不自动重放。

## 重复验收门槛

1. 同一账号通过界面完成三轮单页预览、修改、发布和实际访问；预览中的按钮或键盘操作须有效。
2. 预览后改文件，旧确认不能发布；刷新预览后重新确认可完成；刷新页面不重复发布。
3. 一轮故意构建失败能显示原因，旧版本继续可访问，失败资源回收后可修复重发。
4. 工单修改并重新发布后，原工单、账号与权限保留。只验证兼容性修改，不将其泛化为任意数据库结构迁移。
5. 亮暗主题、聊天稳定、预览关闭/重新打开和不支持工程提示均检查。

记录每轮请求、预览、发布和实际访问时间，逐项注明自动化、真实集群及人工介入。三轮只能说明本批回归，不代表大规模可靠性或已获商业上线资格。真实客户数据仍以前述独立备份和恢复门槛为前提。
