# 个人存储使用手册

## 查看空间

登录 LibreChat，打开“我的空间 → Storage & plan”。聊天仍是编程入口。
窗口分别显示个人文件、项目数据库、私有对象存储、私有镜像与额外应用盘。
所有分类都获得新鲜样本时显示受管逻辑用量；否则显示已测小计及未知/过期状态。
更新存在采样延迟，通常等待约半分钟后再查看。

这是用户数据的逻辑大小，不是整个节点的物理磁盘消耗。不计平台镜像、存储副本、
备份、数据库 WAL 和临时构建层。对象的保留历史版本计入；未完成分片上传不计入
完成数据，临时资源由存储服务另行回收。

当前额度分别执行：个人文件延续已有套餐，数据库测试预算 256 MiB，对象桶原生配额
256 MiB，镜像以 Harbor 项目的实际额度为准。当前既有测试用户的 Harbor 原生额度
无限，界面明确显示这一点。分类额度不能相互挪用，也不能把有无限分类的账户宣传为
具有精确、有限的统一硬上限。

## 使用对象存储

个人文件服务准备好后，系统自动创建一个私有桶和受限连接身份。重复登录复用同一
分配，不复制个人卷，不重复创建桶。窗口中显示 Object storage ready 后即可使用。

在聊天中选择 Coding，例如：

> 在我的工程中使用私有对象存储保存上传附件，添加读写测试，测试通过后发布。
> 使用平台自动提供的连接，不要把连接密钥写入代码、聊天或日志。

Coding 可使用 `python -m control_plane.object_cli status` 查看准备状态，使用
`python -m control_plane.object_cli run 工程目录 -- 工程命令` 运行带连接的测试。
工程需要的库安装到自身 `.venv`，下载缓存和虚拟环境计入个人文件盘。
该工具只注入对象连接；数据库测试使用独立的 `database_cli`。

发布成功的应用自动收到 S3_ENDPOINT_URL、S3_BUCKET、AWS_ACCESS_KEY_ID、
AWS_SECRET_ACCESS_KEY、AWS_REGION 等环境变量，以及工程专属 CODECHAT_OBJECT_PREFIX。
应用应将该前缀用于对象名称，避免同一用户自己的不同工程重名。
浏览器和源码不需要持有这些连接密钥。当前 MinIO 走集群内部 HTTP 9000，
没有新增公网 S3 或控制台入口；存储传输 TLS 是后续基础设施改进项。

已经运行的旧应用不会因开通对象存储而被强制重启；需要使用新连接时重新发布。
停止、重新启动、发布失败或移除应用都会保留桶内数据。
当前不提供普通用户销毁整个对象桶的按钮，也不自动清空已完成对象或其历史版本。

## 准备失败或空间不足

准备失败时，从对象存储状态旁点击 Retry，恢复原分配，不会自动换桶或覆盖原数据。
如果提示管理员核查身份，联系管理员；不要通过重复注册尝试恢复数据。
计量服务暂时不可用时会保留旧值并标过期，不会用零掩盖故障。

个人文件盘不足可以从同一窗口选择测试套餐并确认模拟支付；只有实际扩容成功后
才显示新权益。目前测试订单只增加文件容量及应用数，不增加模型余额或对象、镜像
额度。真实支付、对象与镜像套餐扩容、任意额外应用数据盘尚未上线。
对象原生配额不足时应用应向用户显示明确失败，不能吞掉写入错误后声称保存成功。
