# 发布确认与交付说明

更新：2026-11-06。产品优化第一批已上线：完善现有「我的空间 → 应用」的发布与交付体验。本批不改变模型、套餐权益、用户文件、发布控制器或业务数据库。

## 用户操作

1. 在「应用」选择工程并点击发布，或在已有应用上点击更新、重试。先出现发布确认窗口，明确工程目录、未保存文件不包含在构建内、版本切换可能中断及额度消耗规则。
2. 点击「确认并发布」后才提交。取消不会创建发布任务。等待中或清理、核验尚未结束时不能重复发布。
3. 应用卡片同时说明发布结果的含义。「待核验」不会冒充普通构建失败；恢复旧版本只有在清理记录确认后才提供旧版地址。
4. 点击「交付说明」，查看工程、交付状态、可用地址以及业务验收提示。可复制文字交给同事，复制失败时可展开内容手动选择。

说明只包含用户选择分享的工程名称、交付状态、应用地址和验收提示，不包含聊天、源码、日志、内部镜像地址或凭据。分享前仍需检查应用自身的登录和访问规则，平台登录不会自动保护独立应用。

## 状态和限制

- 发布就绪表示已有平台就绪检查结果，不代表业务操作、数据保存、权限或需求验收全部通过。
- 第一批交付时没有业务验收记录接口。第二批新增[编程任务的人工验收](task-acceptance-guide.md)，第三批新增[实际构建与验收关联](release-provenance.md)。新版交付说明只在源码指纹一致时展示发布时冻结的验收项；旧发布没有证据时不回填猜测。
- 应用状态查询失败时，交付说明标记所展示内容为上次确认记录。对外链接不是实时可用性保证。
- 旧版恢复链接要求失败状态、清理完成、恢复目标为上一版本，同时没有待核验错误。正在构建、停止或结果不明确时不提供交付链接。
- 发布响应丢失时不自动重发；刷新列表核对状态。发布接口本身的幂等与核验机制沿用已有实现。
- 构建使用实际开始时的工程文件。第三批记录实际输入指纹并与验收比对，不提供完整不可变源码包下载，也不承诺数据库回滚。
- 费用估算、业务需求清单、项目预算、异常外部通知和持久化交付历史属于后续工作，不将本批界面改进表述为全部完成。

## 验证记录

镜像内构建、静态检查和类型检查通过，构建校验中的 223 项测试通过，其中应用界面测试 14 项。覆盖确认、取消、工程选择、响应丢失不自动重发、待核验、旧版地址条件、剪贴板失败及分享内容范围。没有增加或变更 API、数据库结构，因此未重跑平台后端测试。
