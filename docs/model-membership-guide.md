# 模型、额度与套餐使用手册

更新：2026-11-03。本阶段为内网可信用户提供模拟购买流程，不接收真实付款。

## 用户入口

登录 LibreChat 后，在输入框底栏加号旁选择“聊天”或“编程”。聊天直接调用普通 LLM；编程由 OpenHands 在个人空间执行任务。右侧模型菜单显示实际模型，两种能力分别保存选择；切换能力保留同一对话及上下文。新对话使用管理员设置的默认模型。原生智能体的模型菜单也是实际模型名称，能力名称不充当模型。

通过“我的空间 → 套餐与用量”查看模型余额、累计输入/输出/总 Token、个人磁盘与应用名额。人民币余额是按当前后台结算汇率显示的近似值，实际模型预算以美元记录。初始 1 美元赠送一次，重新登录不会再赠送。

选择基础版或专业版，核对报价后确认模拟支付。订单锁定创建时的汇率、模型额度与资源权益。初始测试结算规则 7.000000 CNY/USD，不是实时汇率；基础版 10 元增加 1.428571 美元模型预算。充值保留已消费金额，同时增加用户与虚拟密钥的预算上限。可以重复购买；较小套餐不缩小已取得的个人磁盘和应用名额。

“模型额度已到账”和“权益已生效”分别说明预算与资源开通结果。暂未完成请等待或重试原订单，不必重新注册。未付款订单可取消。余额耗尽会停止调用，个人文件保留。

## 管理员入口

访问 https://platform.k3s.local:30443/ ，使用具有 `platform-admins` 组权限的账号登录，打开“模型与套餐管理”。普通用户无权读取或保存此配置。

1. 在 LiteLLM 配置真实模型及输入、输出计费单价，确认它们能正常调用。
2. 刷新模型目录，选择允许用户使用的模型，并分别设置普通聊天和 OpenHands 默认模型。
3. 设置人民币/美元结算汇率、套餐售价、增加模型额度、个人磁盘、应用数量及中文说明。
4. 点击“保存模型与套餐”。配置有版本校验；遇到其他管理员已修改的提示，刷新后再核对，不能覆盖他人新配置。
5. 后台约 30 秒同步受管用户及虚拟密钥模型权限；LibreChat 的模型设置也会定期刷新。已有会话保留用户选择，可手工切换，新会话使用默认模型。

当前只配置一个真实模型，因此聊天和编程菜单中均只有该模型；选择能力仍会调用不同的执行路径。增加第二个模型后可独立选择，不能通过伪造模型名称增加选项。

## 计费与恢复约定

- 参考 Token 以当前聊天模型输入/输出各 50% 的价格估算，不计缓存优惠；价格缺失时显示随模型变化，不编造数量。实际消费按 LiteLLM 的金额及 Token 记录展示。现有部署的模型价格仍是待核对上游账单的测试定价，不可据此财务结算。
- `model-billing-controller` 独立执行预算写入与钱包观察。订单任务先提交原预算及绝对目标，再写入 LiteLLM。写入超时、重复确认及重启都复用同一任务；保留 spend。
- 同一账号的额度任务串行。确认到账前必须观察用户和 key 两级上限；发现受管预算被外部改变，订单转人工核验，避免覆盖未知充值。
- 请勿同时在 LiteLLM 手工编辑这些受管预算。外部系统没有预算比较并交换接口，因此不能宣称支持任意外部并发写入的财务保证。
- 配置保存至 `ai_configurations`，GitOps 中的初始配置只作首次默认值，部署不会覆盖管理员已保存设置。模型密钥仍在集群 Secret 与加密凭据中，不出现在管理页面。
- 运维修改 ConfigMap 中的执行镜像后，还须更新 `workspace-controller` Pod 模板的 `codechat.io/config-revision`，使进程重新读取环境变量；只改 ConfigMap 不会更新已运行进程。验收须检查个人运行环境实际镜像 digest，不能只看配置或 ArgoCD Synced。
- 模拟支付不代表银行或支付平台已经收款。真实支付签名验证、退款、订阅续费、税费、严格并发财务结算和对账尚未实现。

## 文件与历史对话

文件夹下载为 ZIP，单包 32 MiB、原始数据 256 MiB、10,000 项、深度 64、生成 30 秒上限，不跟随链接或包含特殊文件。临时压缩包在请求结束清理；失败时可稍后重试或按子目录分批下载。

新对话开启普通聊天模型摘要命名，Coding 对话的命名也走普通模型。历史默认标题可由运维使用 `scripts/repair_chat_titles.py --email <账号>` 先预览数量，再加 `--apply` 修复。只修改本人未手工改名且标题仍等于读取时值的记录，不修改对话消息、ID 或时间排序。模型异常时采用首条消息短摘要；`--retry-fallback --apply` 只重试私有执行记录中尚未被用户修改的备用标题。
