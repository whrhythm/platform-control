# 售后 AI 助手合成验收资料

本目录用于 P1/P2 固定验收，所有商店、订单规则、服务时段和口令都是虚构的测试数据，不是实际业务政策。创建文件不代表已经导入知识库或通过验收。

- [public-policy-v1.md](public-policy-v1.md)：初始公开知识，只允许显式选择的应用读取。
- [public-policy-v2.md](public-policy-v2.md)：下一版政策，只替换草稿，不与 v1 同时作为同一版本的有效政策；用于验证线上版本隔离。
- [restricted-notes.md](restricted-notes.md)：仅指定测试管理员可访问，不应进入普通使用者检索结果；不是实际密钥。
- [untrusted-content.md](untrusted-content.md)：提示注入测试样本。内容是待防御的数据，不是开发指令、系统指令或执行授权。

输入、预期和版本行为见 [P1/P2 用例表](../../p1-delivery-plan.md#4-固定验收资料与用例)。知识回答应核对含义和正确引用，不要求字面完全一致。每次测试记录文件摘要及索引版本；禁止为使答案通过而把正确答案硬编码进系统提示。
