# 星桥个人空间使用手册

更新：2026-11-04。普通用户入口为星桥（基于 LibreChat）；后面的资源申请接口和管理台操作供管理员或开发调试使用。

编程入口新增了工程选择、工作方式和审批配置。请先阅读[编程设置使用手册](agent-workbench-guide.md)：选择 OpenHands 后，在「编程设置」选择工程文件夹并保存，再发送编程指令。当前每条命令最多 180 秒，整个任务最多 30 分钟；不是整个任务只能执行 180 秒。

## 1. 当前能做什么

打开 `https://chat.k3s.local:30443/`，通过 Authentik 注册或登录。登录时自动准备或复用个人空间、模型凭据；已有账号无需重新注册，不用手工填写 LiteLLM key。空间准备可能需要等待一次容器启动；重复访问不会重复申请磁盘。

编程操作保持在主聊天：在左上角模型选择器选择“OpenHands · 编程助手”，配置当前工程后描述创建或修改工程、运行测试的要求；选择普通模型可继续讨论需求，普通聊天不启动 OpenHands。切换保留当前对话上下文，执行过程中不能切换。原生智能体入口仍保留；写作、音乐专用能力尚未开放。例如：“在当前工程创建监听 8080 的 Python HTTP 服务，添加并运行测试。”点击最左侧、新建对话上方的“我的空间”图标，在右侧打开文件和应用工作区，不替换聊天或历史记录。桌面可拖动中间分隔线调整宽度，小屏幕使用覆盖式面板，关闭后回到原聊天。生成源码、依赖缓存和工作文件使用个人磁盘。命令和任务超时请求停止，已生成文件保留。

文件以紧凑的树形列表显示，展开文件夹不会隐藏同级文件。点击文件名打开预览，文件行上的铅笔图标在右侧工作区内打开编辑器，图标悬停显示编辑提示，不再重复显示“编辑”文字。聊天仍可继续使用。下载图标保存到本地，“⋯”菜单里的删除操作须二次确认。编辑器显示文件路径、未保存标记和保存按钮，离开未保存编辑时需要确认。当前支持 UTF-8 文本/代码和常见图片预览；其他格式可下载。保存会检查打开时的版本，发现 Agent 已改动时提示冲突，请保留自己的修改后重新打开。删除目前没有回收站，请先备份。

桌面首次打开个人空间时，右侧工作区默认约 360 像素，优先给聊天留出宽度；用户拖动调整后记住宽度，和原生 Artifact 面板的宽度偏好分开保存。

上传目的地始终显示在固定高度的位置。根目录显示“上传到 /”，点击文件夹后只更换路径；长路径省略显示、悬停查看完整路径，不额外插入一行推动列表。

文件夹行也有下载图标，可把该文件夹与子目录下载成 ZIP。单个包最大 32 MiB，原文件合计最大 256 MiB、最多 10,000 项；不包含链接和特殊文件。生成时文件变化、超限或服务异常会报错，不交付残缺压缩包。编程进度集中显示在可折叠的思考区，同类命令或测试状态只显示一次。新对话自动生成摘要标题，仍可手工改名。

右侧工作区顶部固定显示“空间用量”：已用、额度、百分比进度条和采样时间。总量包含受管文件、依赖缓存、应用数据、对象、镜像和额外应用盘；不是只统计当前文件夹。采样未齐显示“已采样”，未知数据不记为零，刷新失败保留上次结果并自动重试。接近额度时显示清理或升级提醒。头像菜单中的“套餐与用量”与“我的文件”并列，提供模型余额、实际 Token 消耗、磁盘和应用数权益及升级操作。各分类额度独立，不能相互挪用。数据库用量同时计入总量并显示在关联应用中，不提供独立数据库管理入口。具体计量范围见[存储使用手册](storage-accounting-guide.md)。

模拟充值：选择套餐 → 核对模型额度、磁盘、应用数与价格 → 点击“确认模拟支付（不扣款）”。先观察“模型额度已到账 LiteLLM”，再等待“权益已生效”；扩容观察通过才更新容量。注册赠送 1 美元，仅一次。当前基础版售价 10 元，增加 10 元等值模型额度并获得 4 GiB/5 个应用；专业版 20 元，增加 20 元等值模型额度并获得 8 GiB/10 个应用。结算汇率由后台配置，初始测试值为 7 人民币/美元：10 元增加 1.428571 美元。再次购买可以补充模型额度，历史消费不清零，已取得的较高磁盘和应用权益不缩小。

不同模型单价不同，页面的 Token 数是参考估算，并非保证的固定数量；实际累计输入、输出及总 Token 来自 LiteLLM。余额观察可能延迟约 30 秒，过期样本会标注。待确认订单可以取消，失败后重试同一订单；提示人工核验时联系管理员，不重复下单。停止、失败或关闭窗口不会删除个人数据。真实支付、自动续费、到期、退款与降级尚未接入，当前不实际扣款。详见[模型与套餐手册](model-membership-guide.md)。

套餐页同时列出每个发布应用的 CPU/内存上限：免费 0.25 核 / 256 MiB、基础 0.5 核 / 512 MiB、专业 1 核 / 1024 MiB（1 GiB）。以已生效权益和页面显示为准。CPU 达上限会限速，内存超限可能重启；并非保证独占 CPU，也不是全部应用共用一个上限。当前自动使用套餐规格，尚无用户自行选择更小规格的入口。套餐升级生效后控制器自动调整已有正常应用，可能短暂重启，不需要重新编译。编程、镜像构建和共享数据库服务有独立限制。管理台「模型与套餐」可配置新订单的单应用 CPU/内存，上线后不会擅自改写已购权益。

发布时在同一聊天说：“测试通过后，把 demo 构建镜像、推送到我的私有仓库并部署。”工程需要 Dockerfile，服务监听 `0.0.0.0:8080`，容器文件须允许 UID 10001 读取，建议 COPY 使用 `--chown=10001:10001`。平台发布工具只提交一次后台任务，然后结束本轮；“已提交”不代表“已发布”。在应用列表观察排队、构建、部署或失败；只有运行且出现访问地址后才打开应用。失败不会自动循环重试，也不应修改业务代码来绕过基础设施错误。

工作区用「文件／应用」分段导航切换。应用页可选择工程并发布；每个应用按名称和状态、访问地址、CPU/内存用量、操作入口的顺序显示。运行日志和更新发布直接可见，启停及删除位于「应用操作」菜单；删除需要确认，只删除运行资源，不删除工程文件。没有指标样本时明确显示等待采样，不使用虚构的零值。已确认绑定数据库的应用显示实际占用、预留容量和采样时间；没有数据库的应用不显示这一块。仍无独立数据库管理入口，预留容量不能误读为数据库强制写入硬限额。

「套餐与用量」位于头像菜单，和原生「我的文件」并列。聊天顶部的选择器可以选模型、OpenHands 编程助手或原生 Agent。普通模型与 OpenHands 之间的切换作用于同一对话的后续消息。

发布失败会显示阶段说明；即使文件面板关闭，也会提示失败。清理状态单独展示，清理完成后可修复并点击 Retry release，不自动循环重新构建。如果恢复了上次成功版本，可通过旧版本链接继续访问；“上次版本可用”不表示这次发布成功。需要管理员处理的失败不开放自动重试。

发布控制器查询 Kubernetes 状态超时时，应用保留上次确认的状态，控制器会自动重试。连接恢复后，应用列表按最新检查结果更新。如果发布写入的结果无法确认，控制器暂停该任务，由管理员核对集群资源后再处理。

平台管理员在管理台左栏进入「待核验」。逐项核对原发布意图、集群实际状态和差异。证据确认时点击「核验并恢复」，确认后控制器会再次读取集群证据，匹配时从原阶段继续，发生变化时保持暂停。页面下方的审计列出提交人、应用、核验结果和时间。缺少写入凭证的旧记录、证据不一致的记录和无法读取的构建凭据记录只能人工核验。普通查询超时不会出现在该队列。

`https://platform.k3s.local:30443/` 为管理员控制台。其原有资源申请记录中，“方案已生成”只表示规划完成；实际个人空间、项目数据库、对象存储及应用状态应以 LibreChat 对应入口的观测结果为准。

平台管理员可以从左栏进入「用户与资源」。列表按已建工作空间记录的用户分页，支持搜索 OIDC 用户标识、空间名称、空间 ID 或完整命名空间。点击「查看详情」查看个人空间、套餐、应用及配额、五类存储、模型美元额度和已记录 Token。用量显示最近采样时间，过期样本会标注，缺失数据以「—」显示。此页是只读盘点，未建工作空间的 Authentik 账号不在列表中。

## 2. 首次访问

平台地址：<https://platform.k3s.local:30443/>。

登录服务：<https://authentik.k3s.local:30443/>。

两个域名都需要正确解析，并信任运维提供的内部 CA。不要把登录地址改为 IP，OIDC 回调和证书校验需要使用上述完整域名及端口。

### 方法 A：客户端能直接访问 Tailscale 地址

在客户端 DNS 或 hosts 中配置：

```text
100.92.98.122 platform.k3s.local authentik.k3s.local
```

位于服务器原局域网的客户端，可将该地址换为 `192.168.10.30`。

### 方法 B：通过 SSH 隧道访问

如果浏览器不能直接访问目标 Tailscale 网络，在可正常 SSH 的终端（例如 WSL）执行并保持运行：

```bash
ssh -N -L 127.0.0.1:30443:192.168.10.30:30443 edge@100.92.98.122
```

将客户端的两个域名解析到本机：

```text
127.0.0.1 platform.k3s.local authentik.k3s.local
```

两种方法选一种；不要为同一域名同时保留冲突的 hosts 条目。Windows hosts 文件是 `C:\Windows\System32\drivers\etc\hosts`，通常需要管理员权限编辑。

隧道方法下，关闭 SSH 终端会中断浏览器连接，但不会停止集群中的平台服务。若本地 30443 已被占用，先关闭冲突程序；直接改成本地其他端口会导致当前 OIDC 回调地址不匹配。

### 信任内部 CA

请从集群管理员获取 `internal-ca.crt`，核对来源后导入浏览器使用的受信任根证书存储。Windows 通常可双击证书，选择安装到当前用户的“受信任的根证书颁发机构”，然后重新打开浏览器。受组织管理的电脑请采用组织规定的证书分发方式。

运维可以导出公开 CA；以下命令不导出私钥：

```bash
kubectl -n platform-system get configmap platform-ca \
  -o jsonpath='{.data.internal-ca\.crt}' > internal-ca.crt
```

如需使用本地配置文件，在命令中增加 `--kubeconfig /mnt/e/Downloads/Blank/.kube/config`。不要关闭浏览器或服务端的证书校验来代替安装 CA。

## 3. 账号与登录

1. 打开平台，点击“使用 Authentik 登录”。
2. 输入 Authentik 用户名和密码，完成组织要求的其他验证。
3. 首次访问会出现授权确认，确认应用为“开发空间”后继续。
4. 回到平台，进入个人空间创建页或已有项目工作台。

Authentik 账号与 SSH 账号是两个系统，不能假定密码相同。本次部署没有修改现有 Authentik 用户密码；文档不保存密码。

当前未配置自助注册流程。新用户需由 Authentik 管理员在管理控制台的用户页面创建、设置初始密码并通过合适渠道交付。无需为普通平台用户创建 Linux 账号或提供 kubeconfig。

访问令牌有效期为 15 分钟，当前界面不自动续期。出现登录过期提示时，刷新页面并重新点击统一登录。当前令牌保存在页面内存中，刷新页面也会回到登录入口；项目和申请记录保存在 PostgreSQL，不会因刷新而丢失。

## 4. 创建个人空间和项目

首次登录后，在“创建你的个人空间”中输入空间名称并提交。每个用户只能创建一个个人空间，也可以由其他空间的 owner 邀请加入。

进入空间后，在“新建项目”中输入名称，例如 `my-project`。项目名称使用小写英文字母、数字和连字符，首尾使用字母或数字；不要包含空格、斜杠或中文。界面使用同样的规则约束资源名称。

通过“当前空间”和“当前项目”切换查看范围。当前权限模型为租户级共享：同一空间的成员可按角色查看该空间全部项目，尚未提供同一租户内部的私有项目权限。

## 5. 申请资源

选择项目后，在“申请新资源”中选择类型、填写名称并提交。

| 类型 | 操作 | 当前结果 |
| --- | --- | --- |
| 工作空间 | 填写资源名 | 预留容量并生成独立工作空间的部署方案 |
| 编程助手 | 选择本项目尚未取消的工作空间 | 生成 OpenHands 绑定方案；一个工作空间最多一个助手分配 |
| 数据库 | 填写资源名 | 生成独立数据库与角色的开通要求；不返回可用连接串 |
| 对象存储 | 填写资源名 | 生成独立 bucket、策略及配额方案；不生成可用访问密钥 |
| 应用部署 | 填写资源名和已审核镜像地址 | 预留容量并生成部署方案；不创建公开项目域名 |

部署镜像必须位于 `harbor.k3s.local/internal/`，并包含不可变 digest，例如：

```text
harbor.k3s.local/internal/my-app@sha256:<64位十六进制摘要>
```

`latest` 等普通标签不能作为发布依据；上述 `<...>` 是格式说明，不能原样提交。

当前界面采用默认规格，更多规格与开发/生产环境字段见 API 契约；界面尚未提供这些字段的完整编辑器。

| 资源 | 默认预留 |
| --- | --- |
| 工作空间 | 500m CPU、1024 MiB 内存、5 GiB 存储 |
| 应用部署 | 250m CPU、512 MiB 内存 |
| 对象存储 | 1 GiB 存储 |
| 编程助手 | 绑定已有工作空间，不另计一套 CPU/内存；仍占一条资源数量额度 |
| 数据库 | 当前只计资源数量；尚无数据库磁盘硬配额承诺 |

## 6. 状态、额度和取消

| 界面状态 | 含义 |
| --- | --- |
| 已提交 / requested | 已保存申请并预留容量，等待计划 worker |
| 方案已生成 / planned | 已生成计划，尚未实际开通；API 中 executable=false |
| 已取消 / cancelled | 未开通的申请已取消并释放预留，记录保留 |

点击“刷新”查看最新状态。计划 worker 通常每两秒检查任务；这不是开通耗时保证。当前没有终端、运行测试、已发布网址或真实数据库访问按钮。

空间默认额度为 3 个项目、4000m CPU、8192 MiB 内存、40 GiB 存储、20 条有效资源记录；管理员可以调整。界面显示的是**预留容量**，不是实际 CPU 使用、磁盘文件大小或费用。申请尚未运行也会占预留，以避免并发超额。

取消申请时点击对应记录的“取消申请”。工作空间已绑定助手时，先取消助手再取消工作空间。已取消记录不会恢复运行；重新申请需提交新申请。

网络异常或冲突提示时，先刷新列表确认提交结果，避免反复点击。API 调用方应保留同一个 Idempotency-Key 重试；取消后复用原 key 仍返回原来的已取消记录。

## 7. 管理员与成员

| 角色 | 能力 |
| --- | --- |
| owner | 管理本空间项目与申请、管理成员、查看审计 |
| admin | 管理本空间项目与申请、查看成员和审计；不能修改 owner 或成员角色 |
| developer | 查看并创建项目与资源申请、取消未开通申请 |
| viewer | 只读项目、资源、任务与额度 |
| 平台管理员 | 通过专用管理 API 列出租户、调整租户总额度；不会自动获得普通项目接口的成员权限 |

现有 `akadmin` 已加入 Authentik 的 `platform-admins` 组。其他平台管理员由 Authentik 管理员审核后加入该组；组自身不授予 Authentik 超级管理员权限。修改身份组后需重新登录，使新令牌携带更新的组声明。

成员管理、额度调整和审计当前提供 API，尚无完整的管理员界面。由具备对应权限的人员按 OpenAPI 操作：

| 接口 | 权限 |
| --- | --- |
| PUT `/v1/tenants/{tenant_id}/members` | owner；按用户的 OIDC subject 分配 admin/developer/viewer，subject 不是用户名 |
| DELETE `/v1/tenants/{tenant_id}/members/{subject}` | owner；不能移除 owner |
| GET `/v1/tenants/{tenant_id}/quota` | 本空间成员 |
| GET `/v1/tenants/{tenant_id}/audit` | owner/admin |
| GET `/v1/admin/tenants` | 平台管理员 |
| PUT `/v1/admin/tenants/{tenant_id}/quota` | 平台管理员；新额度不得低于已预留容量 |

接口文档为平台的 `/docs` 与 `/openapi.json`。业务调用使用当前用户的 access token，不使用 ID token、共享管理员 token 或自报身份的请求头；不要把 token 发到聊天、工单或仓库中。

## 8. 常见问题

| 现象 | 检查与处理 |
| --- | --- |
| 无法解析域名 | 检查两个域名的 DNS/hosts 条目是否正确、是否存在冲突 |
| 连接超时 | 检查 Tailscale 或 SSH 隧道，确认本地 30443 未被其他程序占用 |
| 证书不受信任 | 安装正确内部 CA，核对域名；不要直接使用 IP 或跳过校验 |
| redirect_uri 不匹配 | 保持完整平台 URL `https://platform.k3s.local:30443/`，检查登录 provider 的严格回调配置 |
| 401 | 令牌缺失或过期，重新登录；运维再检查 issuer/audience/scope/JWKS |
| 403 | 当前角色不具备该操作权限；不是让用户改请求头自报 admin |
| 404 | 记录不存在或不属于当前用户可访问范围，检查空间/项目选择 |
| 409 | 额度不足、同名资源、重复幂等键冲突或仍有关联助手，先刷新记录 |
| 申请一直已提交 | 运维检查 platform-worker 日志和数据库连接；不要手工将记录改为运行中 |
| Argo CD 健康但页面打不开 | 同时检查 ApisixRoute/ApisixTls 的 Accepted 条件；健康不代表路由已下发 |
| 刷新后需要重新登录 | 当前令牌仅保存在页面内存中，是已知行为；数据仍保存在服务端 |

## 9. 后续开放范围

数据库接入与销毁的技术说明见[项目数据库使用手册](project-databases-guide.md)。2026-11-04 起个人空间不再提供数据库管理面板；该手册中早期数据库入口的截图和操作路径不适用于当前用户界面。

真实支付、公开受信任 HTTPS 和完整桌面安装包尚未开放。数据库与对象存储后端已有接入能力，相关数据纳入受管逻辑用量；用户界面不再单独展示数据库管理。应用数量和个人磁盘额度以已生效套餐为准。构建临时空间及运行资源有独立上限，不等同于可任意挪用的个人磁盘容量。

当前集群存在 k3s 节点 PodCIDR `10.42.0.0/24` 与 Calico 地址池 `172.16.0.0/16` 不一致，已观察到服务流量被转换为节点地址。开放真实租户代码执行前，必须整改并实测跨租户网络拒绝；当前的 API 越权测试不能代替运行环境隔离验收。
