### 工程版本的首版边界

1. 在“我的空间”的工程操作中提供“创建恢复点”和“版本历史”，聊天也可通过同一受控接口调用。预览差异不占据聊天主界面。
2. 先实现“恢复为新工程目录”，保留原目录；后续覆盖式恢复必须先展示变更与冲突、再次确认，并先保存当前状态。应用数据库变更不随源码恢复自动回滚。
3. 版本包含内容清单、哈希、创建时间、关联任务；记录不可变。版本存储由平台服务控制，不能仅放在用户/Agent 能任意修改的隐藏文件夹中。
4. 不强制初始化或覆盖用户自己的 Git 仓库。源码恢复点与完整卷备份是两种不同能力；依赖缓存、构建产物、版本控制内部元数据的包含规则需在创建前明示。
5. 版本存储计入逻辑总量，显示版本占用。容量不足时拒绝新建并说明原因；清理历史由用户或明确的保留策略执行，不静默删除当前工程文件。
6. 创建恢复点时确认工程无活跃写入任务；统一人工编辑和 Agent 写入的并发控制，检测变更并失败重试，禁止把混合时刻的文件宣称为一致版本。
7. 验收：上传、Agent 修改、人工修改后分别可查看差异；旧恢复点不会随新修改改变；跨用户不可读取；超额、并发修改、恢复失败有明确结果；原始工程不变。

### 任务状态语义

- 普通状态查询超时：保留上次确认状态，自动重试。
- 尚未执行就发现账号凭据/模型不可用：失败并明确原因，不调用模型或工具。
- 执行器重启或外部写入结果不明确：标记中断/待核验，不盲目重放。核验后创建有来源关联的新任务。
- 浏览器断线/刷新：重新读取任务状态及已有事件，不能创建重复任务。
- “完成”必须有执行结果；“清理完成”必须有资源观测依据。

### 备份范围与恢复顺序

备份清单应包含用户卷、共享 PostgreSQL 内各服务及业务库、LibreChat MongoDB、MinIO 对象、Harbor 镜像与元数据、平台配置以及独立保护的加密密钥。GitOps 仓库不能替代用户数据和凭据备份。

恢复顺序：基础配置与受保护密钥 → 数据库/身份映射 → 文件与对象副本 → 核对卷绑定和所有权 → 文件服务 → 应用及 Agent。恢复环境默认禁止真实支付、外部通知和历史任务自动执行。只有经过核验后才切流量。

单机内部 MinIO 可作为本地备份暂存，但不能称作异机容灾。当前本地演练不承诺生产 RPO/RTO；正式目标需结合数据规模、备份频率和实际恢复耗时确定。

## 阶段 2：Langflow 单场景试点

首个场景：在 LibreChat 选择工程 → 生成项目说明/部署文档 → 流式或阶段进度反馈 → 预览 → 用户确认保存到我的空间。

- Langflow 编辑器先只面向管理员/可信流程作者；普通用户调用审核后的版本化流程。
- Platform Control 验证身份、流程权限、目录范围和预算；使用服务端身份上下文，不信任客户端传来的 user_id、路径或额度。
- 模型调用归属实际发起用户，继续经 LiteLLM 计量；平台管理密钥不暴露给流程/浏览器。
- 每次运行独立上下文、临时文件和结果，按任务授权读取选定工程。输出文件进入已有文件接口与容量检查。
- 任何自定义代码或不可信执行都需要独立执行环境。共享 Langflow 账户/进程本身不构成多租户隔离。
- 必须验证取消、超时、模型额度不足、文档生成失败、保存冲突和重复提交。不同用户的文件/对话不能串用。
- 不同时上线 Dify。保留工作流适配边界，避免与具体引擎绑定用户身份、存储或计费事实。

官方依据：[Langflow 安全边界](https://docs.langflow.org/security)、[通过 MCP 暴露流程](https://docs.langflow.org/mcp-server)。具体部署版本、API、进度语义和隔离实现留待试点验证，不假定接入 MCP 即具备长任务恢复。

## 本轮验收与运行方式

- `scripts/drill_local_recovery.py`：只创建 localhost 随机临时 PostgreSQL 容器，使用真实 Alembic 迁移；不接受生产 URL、kubeconfig 或用户目录参数。
- 在项目根目录执行 `.venv/bin/python scripts/drill_local_recovery.py`。默认已有镜像 postgres:16；可用 PLATFORM_TEST_POSTGRES_IMAGE 显式选择兼容镜像。
- 成功：4 个文件（中文文本、源码、隐藏配置、二进制）哈希一致，恢复用户环境与套餐，独立密钥可解密合成凭据，原目录后续修改保留；临时文件与容器结束后清理。
- 最新实测迁移版本 `0019_project_versions`，本地演练约 7.17 秒；增加了加密源码恢复点恢复校验。这个数字不是生产恢复时限。
- Agent 相关测试：26 passed、1 skipped。跳过项需要独立模拟环境，未声称本轮重跑完整构建发布流程。
