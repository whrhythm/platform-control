# 代码运行套餐与保存文件

管理员现从“平台管理 → 套餐与配额管理 → 聊天中的运行代码”设置后续订单额度。它与 OpenHands 命令、镜像构建的规格分别配置，见[统一配额使用说明](unified-quota-management.md)。

## 产品规则

聊天代码块的「运行代码」和智能体的默认 CodeAPI 执行都通过控制面的计量网关。OpenHands 项目构建沿用原有工作空间和构建流程，不重复扣此处次数。

兼容旧套餐快照的默认值：免费 30 次/月、单次 10 秒、并发 1；基础 300 次/月、单次 15 秒、并发 1；专业 1500 次/月、单次 15 秒、并发 2。管理员可在模型与套餐管理修改后续订单权益。单次程序内存上限 256 MiB，服务整体另有固定资源限制。

按北京时间自然月重置，不结转。额度是运行次数，不冒充 CPU 实际使用秒数，也不从 LiteLLM 的 tokens 余额扣费。升级保留当月已用次数并提高上限，购买低档套餐不降低已开通权益；当前订单仍为模拟支付，未新增真实支付或自动续订。

提交前在数据库中锁定用户空间并预留一次额度。程序报错、超过运行时限和结果不明确均计次；明确的执行前拒绝不计次。相同幂等键不重复执行。网络错误不自动重试代码。结果不明确时暂占并发名额，默认 180 秒后释放；底层请求等待最长 90 秒，断开连接会移除尚未运行的队列任务，已经运行的任务受单次时限约束。释放名额不退款、不代表任务成功。

输入文件上传另有月度次数和传输量上限：最多当月运行上限的 4 倍次上传、每次运行额度对应 16 MiB 的月度上传总额。并发和程序执行共享准入限制。额度用完仍可下载已有结果、删除临时文件、保存到个人空间。

## 文件保存

结果区域提供「保存到我的空间」，允许选择生成文件、目标目录和文件名。复用 LibreChat 已鉴权下载与个人文件上传接口，后端继续验证所有权、路径和剩余容量。禁止自动覆盖；同名冲突需改名或换目录。保存超时提示先核对文件，不自动重复上传。

临时计算不挂载个人空间。保存后的文件按真实大小计入个人磁盘，之后可预览、编辑、删除。未保存产物仍受临时服务容量与生命周期约束；临时文件过期后不能承诺恢复。单文件保存上限为既有上传接口的 16 MiB。

## API 与部署边界

- 套餐增加 `code_runs_monthly`、`code_timeout_seconds`、`code_concurrency`，使用已激活的套餐快照作为权限来源。
- 容量接口增加 `code_execution`，包含月份、已用次数、剩余次数、并发占用和当前限制。
- `POST /internal/v1/codeapi/exec` 验证 LibreChat EdDSA JWT，签名中携带真实 OpenID issuer/subject，不能从浏览器请求体指定用户。控制面转发时强制套餐时限。
- 网关只允许默认执行和必要的文件接口，拒绝其他命令、持久运行或任意 URL 转发。CodeAPI 网络入口只接受控制面，LibreChat 不可绕过准入直连。
- 超额、并发已满返回 429；重复键返回 409；身份错误返回 403；上游不明确故障返回 503。日志、计量表均不保存用户代码和凭据。
- 迁移 `0018_code_execution` 保存执行预留及上传计量。API 和工作空间控制器须一起升级；后者负责激活订单权益。

所有临时产物另受独立 MinIO bucket 的 2 GiB 总容量和一天生命周期约束。这是共享服务保护，不等于每个用户获得 2 GiB 临时磁盘。
