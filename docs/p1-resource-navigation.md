## 知识与分享的后续契约

知识库是资料资产，知识检索是工具，业务助手是使用能力的发布成果。选择知识检索后选择/新建知识库，再上传资料；支持空库，待资料就绪后才能声称可检索。编辑支持格式明确，PDF/Word 第一版优先预览/替换，不把提取文本改动当作修改原文件。保存形成新原文修订，自动索引，旧任务不覆盖新结果；正式发布的助手仍固定已确认知识版本。删除先查引用并撤销相应访问，不能只删列表。

成员额度为创建者预算内上限而非转账；已用和在途预占不因撤销/修改上限清零。未知费用继续核验。首发公共访问限定登录用户，匿名访问不随 UI 开放。邀请对象核验、接受、取消/撤销、到期和费用承担必须可见；错误提示不泄露账号敏感状态。公开使用不公开工具凭据、开发目录、私人记忆或所有知识原文。

## 个人工具复用增量

- 原生工具库「我创建的」展示账号拥有的 Action。添加到另一个本人智能体时沿用同一工具 ID，智能体分别保存引用。移除引用保留工具本体。复用工具只在所有者会话加载，继续通过现有 Action 运行和地址检查。
- 资料空间的「工具」定位到个人空间根目录的 `tools`。项目文件页使用相同入口，定位到 `<项目根目录>/tools`。文件通过既有上传、预览和下载流程管理。工具定义的导入与运行沿用原生 Action，资料空间内的编辑不会改变已绑定定义。
- 首个验收场景使用同一报价工具。核对原始文件可见、同一 Action 被两个本人智能体引用和实际调用、移除第二个引用后第一个仍可调用。
