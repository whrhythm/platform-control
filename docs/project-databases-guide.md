# 项目数据库使用手册

1. 在主聊天选择 **Coding**，让助手在个人空间的一个工程目录中创建代码。
2. 打开 **我的空间 → Databases（数据库）**，选择工程目录，点击 **Set up project database**。等待 **Database ready**；重复申请不会新建第二个数据库。
3. 在聊天里说：“使用这个工程的托管数据库，运行数据库读写测试，测试通过后发布。连接从环境 DATABASE_URL 读取，不写入源码。”助手可以调用平台工具运行迁移和测试。该工程下一次发布时会自动取得数据库连接；创建数据库本身不会重启已有应用。
4. 数据库面板显示实际用量、预留额度、最后测量时间和失败原因。**Storage & plan** 将托管数据库实际用量加入逻辑空间账本。正常约每 30 秒测量；过期或失败的测量不当作零。
5. 初始数据库额度额外提供 **256 MiB**，最多两个工程、每个预留 **128 MiB**。已有文件盘额度保持原值。当前数据库额度用于限制申请和提示超量，**没有实现超量后强制停止写入**。
6. 编译失败、发布失败、停止或删除应用都不会自动删除数据库。确需销毁时，先删除该工程的已部署应用，再在数据库面板点击删除并输入完整工程目录确认。此操作永久删除数据库数据，保留工程文件。

当前数据库绑定工程相对目录；移动/改名目录不会自动迁移绑定。数据库扩容付费尚未开放，文件套餐升级不会同时提高数据库额度。MinIO、镜像和应用数据卷尚未接入完整计量，所以界面仍标记总用量不完整。真实付款、自动续费及到期处理仍未实现。

## 运维和实现

部署前由平台仓库脚本 `scripts/bootstrap_project_databases.py` 创建非超级用户的分配账号和持久归属记录。凭据只保存在集群 Secret；业务 API 不挂载分配账号。数据库初始化、计量和销毁由现有 application-controller 执行，复用已验证的个人 namespace RoleBinding。

OpenHands 通过专用工具把连接注入项目子进程，公开 CA 临时文件随工具结束删除。应用在下一次发布时引用连接 Secret 和只读 CA。连接必须验证 PostgreSQL CA。源码和镜像构建上下文不需要数据库密码。

Python 依赖源可以通过 `PLATFORM_WORKSPACE_PIP_INDEX_URL` 配置为不含凭据的 HTTPS 地址。该集群已启用[清华 PyPI 镜像](https://mirrors.tuna.tsinghua.edu.cn/help/pypi/)，以解决默认源下载速度不足。个人 pip/uv 环境自动使用；Dockerfile 在安装依赖之前声明 `ARG PIP_INDEX_URL`，平台构建任务会传入同一地址。依赖缓存仍在个人卷。现有镜像不因软件源调整自动重建。

失败记录不会自动重新申请新数据库。普通失败可点击重试；归属不明、Secret 写入结果不明或 UID 不匹配时显示需管理员检查，禁止按名称接管或删除不明资源。已接受的明确销毁操作失败后保留记录和额度预留，解决失败并完成实际销毁后才释放额度。
