# 售后工单样板 v1

本项目由星桥复制到你的个人目录，之后可以通过聊天或文件编辑继续修改。

- `app.py`：工单、邀请、应用账号与 CSV 导出接口。
- `index.html`：中文界面。`#preview` 模式只有浏览器内的示例数据，不发送网络请求，不代表真实数据库或权限验收。
- `settings.json`：应用名称、模板版本和首次管理员口令的不可逆摘要。管理员口令通过星桥项目页单独查看，不能从摘要恢复。
- `Dockerfile`：使用固定的 Python 运行镜像，不在每次构建下载依赖。

应用使用平台绑定的 `DATABASE_URL`。不要把真实数据库口令写进源码。首次启动只创建缺失表和管理员账号；之后重新构建、发布、停止或启动不会清空工单和账号，也不会重置管理员口令。修改表结构时需要单独设计兼容的数据迁移，不能使用删表重建。

管理员账号为 `owner`。首次发布后登录，选择“邀请同事”，创建一次性、7 天有效的处理人或只读邀请。处理人可登记和更新工单；只读用户只能查看与筛选；仅管理员可以邀请和导出。应用账号与编程平台账号分开，没有平台源码或发布权限。邀请链接含一次性凭据，不要公开发布。

当前列表最多显示 500 条，导出最多 5000 条；超出需要缩小筛选范围。并发编辑会提示冲突而不覆盖别人修改。此样板用于内部示例试点，不是完整客服、CRM 或企业账号管理系统；暂不包含邮件通知、账号停用、密码找回、附件和完整业务审计。

验收：登记 → 刷新后查到 → 邀请处理人 → 分配并更新状态 → 筛选 → 管理员导出且只读用户无法导出 → 修改页面名称并再次发布 → 原工单、账号和邀请状态保留。
